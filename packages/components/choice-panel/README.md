# C03 `sd-choice-panel` v1.1.0

Independent Shadow DOM Custom Element. No React, backend, credentials, storage or network requests. Load `dist/sd-choice-panel.js` as ESM. Demo: `demo/index.html` (serve over HTTP). Build all: `npm run build:components`; test: `node --test packages/components/choice-panel/tests/*.test.mjs`.

Properties (set on the DOM element, never JSON attributes): `{"question": "QuestionV1|null", "busy": "boolean", "disabled": "boolean", "allowCustom": "boolean", "i18n": "Record<string,string>"}`. Set localized `i18n` labels; no German literals in source. All text rendered via textContent, never HTML from input. Events: `{"sd:answer-submit": "Pick<AnswerSubmitV1,questionId|selectedOptionId|customAnswer>"}`; bubbles/composed. Host owns business state and errors/retry.

C03 dispatches one answer per question until host clears busy after error or supplies next question; preserves free-text draft on busy/error and limits input to 600 characters. Independent `disabled: boolean` property disables choice buttons, custom answer form and submit() without setting `aria-busy` or rendering a busy status paragraph; clearing `disabled` reactivates inputs and preserves any entered draft. Idempotency/version checks belong to server. C02 displays immutable supplied segments with author labels and persistent green solo contribution color; no history mutation. C01 selection event does not itself start a paid call.
